WEBER Traveler 가스 그릴 사용 방법

그릴은 이미 펼쳐진 상태로 세팅되어 있습니다. 반드시 실외에서만 사용해 주세요.

가스 캔 보관 위치

가스 캔은 실내의 지정된 수납 위치에 보관되어 있습니다. 사용 시에만 밖으로 가져가 사용 후 다시 제자리로 돌려 놓아 주세요.

연료 및 안전 주의사항

  • 사용 연료: EN417 규격 나사식 가스 캔 (약 470 g)
  • 주변 60cm 이내에는 인화성 물질을 두지 마세요.
  • 통풍이 잘 되는 실외에서만 사용하시고, 화기가 켜진 상태에서는 그릴을 이동시키지 마세요.

1. 사용 전 준비 (가스 연결)

  1. 조절 노브가 “OFF”에 있는지, 레귤레이터 밸브가 닫힘 상태인지 확인합니다.
  2. 가스 캔을 레귤레이터에 손으로 돌려 끼워 고정합니다 (공구 사용 금지).
  3. 레귤레이터 밸브를 열고, 연결 부위에 비눗물을 발라 기포가 생기지 않는지 확인합니다.

기포가 생기면 가스가 새고 있는 것입니다. 즉시 밸브를 닫고 다시 연결해 보시고, 개선되지 않으면 사용을 중지해 주세요.

2. 예열

  1. 뚜껑을 열고 다음 단계에 따라 점화합니다.
  2. 뚜껑을 닫고 “High”로 설정한 후 10–15분 정도 예열합니다 (온도계 약 260℃가 기준).
  3. 예열 후 스테인리스 브러시로 그릴을 가볍게 브러싱합니다.

3. 점화 절차

  1. 뚜껑을 연 상태로 둡니다.
  2. 조절 노브가 “OFF”인지 다시 확인합니다.
  3. 레귤레이터 밸브를 엽니다.
  4. 노브를 누르면서 반시계 방향으로 돌려 “Start/High” 위치에 맞춥니다.
  5. 빨간 점화 버튼을 여러 번 눌러(‘딸깍’ 소리) 불을 붙입니다.
  6. 불꽃이 보이지 않거나 5초 이내에 점화되지 않으면, 노브를 OFF로 돌리고 5분간 환기한 뒤 다시 시도해 주세요.

여러 번 시도해도 점화되지 않을 경우, 설명서의 성냥 점화 방법 또는 트러블슈팅을 참고하시고, 불안할 경우 사용을 중단해 주세요.

4. 소화 및 정리

  1. 조절 노브를 “OFF”로 돌립니다.
  2. 레귤레이터 밸브를 닫습니다.
  3. 그릴이 완전히 식은 후, 드립 팬의 기름 양을 확인하고 필요 시 교체·청소해 주세요.
  4. 장기간 보관 또는 이동 시에는 가스 캔을 분리하여 실외에 보관해 주세요.
